QUESTAO 04 - ATRIBUICAO COMPOSTA E PRECEDENCIA

Estado inicial: a = 1, b = 2, c = 3 e d = 4.

1. a += b + c
   a = 1 + (2 + 3) = 6
   Estado: a = 6, b = 2, c = 3, d = 4.

2. b *= c = d + 2
   A atribuicao e avaliada da direita para a esquerda.
   c = 4 + 2 = 6
   b = 2 * 6 = 12
   Estado: a = 6, b = 12, c = 6, d = 4.

3. d %= a + a + a
   d = 4 % (6 + 6 + 6)
   d = 4 % 18 = 4
   Estado: a = 6, b = 12, c = 6, d = 4.

4. d -= c -= b -= a
   As atribuicoes compostas sao avaliadas da direita para a esquerda.
   b = 12 - 6 = 6
   c = 6 - 6 = 0
   d = 4 - 0 = 4
   Estado: a = 6, b = 6, c = 0, d = 4.

5. a += b += c += 7
   c = 0 + 7 = 7
   b = 6 + 7 = 13
   a = 6 + 13 = 19

Valores finais: a = 19, b = 13, c = 7 e d = 4.

   1 < 5 -> 1 (verdadeiro)

b) 2 * i - 7 <= j - 8
   -5 <= -6 -> 0 (falso)

c) -x + y >= 2.0 * y
   1.1 >= 8.8 -> 0 (falso)

d) x == y
   3.3 == 4.4 -> 0 (falso)

e) !(n - j)
   !(2 - 2) = !0 -> 1 (verdadeiro)

f) !n - j
   (!2) - 2 = 0 - 2 = -2

g) i && j && k
   1 && 2 && 3 -> 1 (verdadeiro)

h) i || j - 3 && k

i) i < j && 2 >= k
   (1 < 2) && (2 >= 3)
   1 && 0 -> 0 (falso)

QUESTAO 06 - INCREMENTOS PREFIXADO E POS-FIXADO

a) No incremento prefixado (++n), a variavel e incrementada antes de seu valor ser usado na atribuicao. Assim, n passa de 5 para 6 e x recebe 6. A saida sera:
   Trecho A: n = 6, x = 6

No incremento pos-fixado (m++), o valor atual e usado primeiro e o incremento ocorre depois. Assim, y recebe 5 e m passa para 6. A saida sera:
   Trecho B: m = 6, y = 5

b) Na chamada printf("%d\t%d\t%d\n", n, n + 1, n++), a variavel n e lida em alguns argumentos e modificada em outro, sem que a linguagem C determine uma ordem de avaliacao entre esses argumentos. Essas operacoes nao sao sequenciadas entre si, o que caracteriza comportamento indefinido. Por isso, o resultado pode variar entre compiladores, configuracoes de otimizacao ou execucoes. A forma segura e realizar o incremento em uma instrucao separada e somente depois imprimir os valores desejados.
